# 存档说明

## 正式版本

本仓库以 **V11** 为第十一届中国数据新闻大赛正式提交版。线上作品地址为：

<https://screen-coach.netlify.app/>

提交时的仓库状态保存在 Git 标签 `submission-v11`。赛后重构只整理以下内容：

- 将制作期文件名改为长期可读的语义化路径；
- 补充 README、方法说明、页面元信息与存档边界；
- 清理版本号和制作过程遗留的代码注释；
- 保持页面正文、数字、图表、插图、布局与交互逻辑不变。

## 未纳入的版本

本地制作档案中存在 V12、V13 等后续尝试。团队已确认这些改动没有成为正式提交版本，因此不进入本仓库的主线，也不作为公开作品版本介绍。

## 数据边界

仓库只保存网页运行所需的聚合数据和散点记录，不包含完整原始采集库、语音文件、转写缓存、模型原始响应或个人化工作材料。这既能保持部署体积可控，也能降低对平台用户信息的二次传播风险。

## 历史口径说明

作品标题中的“1.2亿”以及正文中的部分 B站规模数字，沿用 2026 年正式提交版本的表述，其来源在作品中写作《2025年B站健身跟练趋势报告》。该报告原件未纳入当前仓库，项目本地数据也不能独立派生这些平台规模数字。

为保证参赛作品的历史完整性，赛后存档不回写或改写已提交正文；读者应将上述数字理解为提交版本引用的外部平台口径，而不是本项目自采数据的计算结果。
